# WLSA AI Universe v3: AI Education Pilot

This is the editable source code extracted from the original standalone prototype.

## Files

- `index.html` - interface and application markup
- `styles-1.css`, `styles-2.css` - original CSS, in original order
- `app-1.js`, `app-2.js`, `app-3.js` - original JavaScript, in original order
- `wlsa-logo.png` - embedded image asset extracted from the original prototype

## Running

Open `index.html` in Chrome or Edge. If local browser security restrictions prevent some features, serve this folder with `python -m http.server 8000` and visit http://localhost:8000. No build system is required.
